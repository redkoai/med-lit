# MedLit experience refresh

The first visit should answer: what can I learn from this paper, how do I start, and whose AI account pays?

Palette: paper white #FFFFFF, ice #F2F6F7, ink #173438, teal #007C83, muted plum #5D507D, slate #53666D. Georgia gives the paper headline an academic voice; system sans handles controls and evidence. Left-aligned text, a generous two-column working surface on desktop, one column on phones.

The distinctive element is an interactive paper excerpt beside its supported appraisal question. The source passage highlights in response to a selection. This explains the product while giving the page motion; it is an explicitly fictional example, never a scientific result.

Start paths: connect a personal API key for in-app appraisal; prepare a source packet to use in the user's own ChatGPT; inspect the example without credentials. No company-funded model fallback. No simulated ChatGPT OAuth.

Review against the brief: avoid a generic gradient hero, a wall of feature badges, and an API-key error as the first experience. Motion is limited to a short paper entrance, selected evidence, and press feedback. All content remains readable with reduced motion.
