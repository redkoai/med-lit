# MedLit: research review studio

## Brief and separation

MedLit is the standalone scientific-literature appraisal product. Synaptik is not a module, workspace, identity, or data source for this app. Verified Git roots and remotes differ; MedLit's own origin is https://github.com/redkoai/med-lit.git and its own Vercel project is medlit-evidence-appraisal. Keep this checkout's existing uncommitted work intact.

## Direction

Move away from the prior marketing hero into an immediately usable review studio: compact navigation rail, a paper input and AI connection at the center, and a working evidence example alongside it. The memorable element is a source passage connected to a bias question, not decorative imagery or a wellness world.

Palette: paper #FFFFFF, canvas #F5F6FA, ink #15253E, cobalt #284DE3, mist #EDF0FE, slate #59677A. Severity colors retain their existing meanings. Type: system sans for navigation, headings and findings; Georgia only for quoted source text. Headings 40/46, section titles 22/28, body 15/23, metadata 12/18. Left-aligned, bounded reading lines.

Desktop: navigation rail | review workspace (new-paper form | interactive evidence preview). Mobile: compact header, form, then preview. Reports open with descriptive source/uncertainty states and use tabs for overview, bias/evidence, methods, and citations instead of a wall of score circles. Breakpoints use CSS so server and client markup agree.

Initial critique: the earlier layout was a marketing landing page with a generic large serif headline and repeated rounded cards. This plan replaces that with task-oriented navigation and the actual review workflow. One action-driven finding transition is enough; no background animation loops.

## First-use test

The key-free example uses an explicitly fictional study, not a generated or validated appraisal of a real paper. It runs the production evidence validator, links source quotations to judgments, and cannot be mistaken for a user's saved history. Real papers still use the user's own provider key or the explicit external ChatGPT handoff.
